# Deprecation Notice

**This project has moved to [LocalVoice](https://github.com/CMiller56/LocalVoice).**

### What happened?

The original `VoiceTranscriber` module (speech-to-text) has been incorporated into a larger, more complete offline speech toolkit called **LocalVoice**.

The new repository includes:
- The original `VoiceTranscriber` (STT)
- A new companion `VoiceSynthesizer` (TTS using Piper)
- Unified documentation and integration examples

### Recommended Action

Please use the new repository going forward:

**https://github.com/CMiller56/LocalVoice**

The `VoiceTranscriber` class API has not changed. You can drop the file from the new repo into your project with no modifications required.

This repository is kept only for historical reference and will no longer receive updates.
